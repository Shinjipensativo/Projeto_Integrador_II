# Requisitos do AcessoLab

## Requisitos funcionais

Os requisitos funcionais representam as funções que o sistema deverá realizar.

| Código | Requisito                                        |
| ------ | ------------------------------------------------ |
| RF01   | Cadastrar os alunos e suas matrículas.           |
| RF02   | Validar a matrícula digitada.                    |
| RF03   | Registrar a data e o horário de entrada e saída. |
| RF04   | Liberar a porta para usuários autorizados.       |
| RF05   | Negar o acesso para matrículas não cadastradas.  |
| RF06   | Permitir a consulta do histórico de acessos.     |

## Requisitos não funcionais

Os requisitos não funcionais representam as características de qualidade do sistema.

| Código | Requisito                                                      |
| ------ | -------------------------------------------------------------- |
| RNF01  | O sistema deverá responder em poucos segundos.                 |
| RNF02  | As mensagens deverão ser simples e compreensíveis.             |
| RNF03  | Os registros deverão ser armazenados com segurança.            |
| RNF04  | Somente responsáveis autorizados poderão alterar os cadastros. |
| RNF05  | O sistema deverá ser fácil de utilizar e manter.               |
