# Roteiro da Apresentação Final - AcessoLab

## 1. Introdução

“O AcessoLab surgiu para resolver um problema comum nos laboratórios: alunos entram ou saem sem preencher corretamente a lista de frequência.”

## 2. Proposta

“A solução valida a matrícula, identifica o laboratório escolhido e registra automaticamente a entrada ou a saída.”

## 3. Escopo virtual

“Nesta versão, o projeto foi desenvolvido como um protótipo virtual, conforme autorizado pelo professor. A porta e os sinais do equipamento físico são simulados pela plataforma web.”

## 4. Demonstração

1. Mostrar o cadastro de um aluno;
2. selecionar um laboratório;
3. registrar uma matrícula válida;
4. explicar a porta aberta e o sinal verde;
5. registrar a saída;
6. testar uma matrícula inexistente;
7. mostrar o histórico.

## 5. Tecnologias

“O sistema utiliza Python e Flask no servidor, HTML e CSS na interface e SQLite para armazenar os dados.”

## 6. Resultados

“O protótipo consegue cadastrar alunos, validar matrículas, diferenciar laboratórios, registrar movimentações e demonstrar visualmente a autorização ou negação do acesso.”

## 7. Limitações e melhorias

“A principal limitação é a ausência do circuito físico. Futuramente, a API existente poderá ser conectada a um ESP32, teclado matricial e servo motor.”

## 8. Conclusão

“Mesmo como simulação, o AcessoLab demonstra que a proposta pode melhorar o controle, a organização e a consulta de frequência nos laboratórios.”
